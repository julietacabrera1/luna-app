# IA – LUNA

## Descripción

LUNA es una aplicación web para organizar el día a día de las personas, integrando tareas, eventos y recordatorios en un solo espacio.

## Archivos principales

- **CONSTITUCION.md** → Principios del proyecto.
- **AGENTS.md** → Comandos y reglas para los agentes de IA.
- **memory.md** → Decisiones y datos persistentes del proyecto.
- **docs/** → Kit de especificaciones (contexto, requerimientos, arquitectura, seguridad, etc.).
- **specs/** → Funcionalidades completas con ciclo SDD.
- **src/** → Código fuente de la aplicación.
- **tests/** → Pruebas automáticas.
- **multimedia/** → Imágenes, videos y gráficos generados o elaborados para el proyecto.

## Reglas para las herramientas de IA

1. No inventar datos ni información que no esté respaldada por las especificaciones.
2. Respetar la identidad visual definida en `IDENTIDAD-MARCA.md`.
3. Utilizar sintaxis Markdown correcta en todos los documentos.
4. Mantener coherencia entre las especificaciones y el código.
5. No ejecutar cambios ni código sin revisión humana previa.
6. Cada commit debe corresponder a una tarea pequeña y comprensible.
