# COPILOT – LUNA

## Descripcion
LUNA es una aplicacion web para organizar el dia a dia de las personas, integrando tareas, eventos y recordatorios en un solo espacio.

## Archivos principales
- **CONSTITUCION.md** → Principios del proyecto.  
- **AGENTS.md** → Comandos y reglas para el agente.  
- **memory.md** → Decisiones y datos persistentes.  
- **docs/** → Kit de especificaciones (contexto, requerimientos, arquitectura, seguridad, etc.).  
- **specs/** → Funcionalidades completas con ciclo SDD.  
- **src/** → Codigo fuente de la aplicacion.  
- **tests/** → Pruebas automaticas.  
- **multimedia/** → Imagenes, videos y graficos generados con IA.

## Reglas para Copilot
1. No inventar datos ni informacion que no este en las especificaciones.  
2. Respetar la identidad visual definida en IDENTIDAD-MARCA.md.  
3. Usar sintaxis Markdown real en todos los documentos.  
4. Mantener coherencia entre especificaciones y codigo.  
5. No ejecutar codigo sin revision humana previa.  
6. Cada commit debe corresponder a una tarea pequeña y comprensible.
