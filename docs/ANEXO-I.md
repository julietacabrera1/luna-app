# ANEXO I – HERRAMIENTAS DE INTELIGENCIA ARTIFICIAL UTILIZADAS EN LUNA

El presente anexo detalla las herramientas utilizadas durante el desarrollo del proyecto LUNA, sus aplicaciones, los motivos de selección y las medidas consideradas para reducir posibles riesgos.

| Uso | Herramienta y modelo | Empresa y plan | Motivo de la elección | Riesgos y mitigación |
|-----|----------------------|----------------|----------------------|---------------------|
| Programación | ChatGPT y Visual Studio Code | OpenAI / Microsoft – Plan gratuito | Se utilizaron como apoyo para desarrollar funcionalidades, revisar código, resolver errores y mejorar la organización del proyecto. | Las respuestas generadas pueden contener errores o soluciones que no se adapten al proyecto. Para reducir este riesgo, el código se revisó, probó y ajustó antes de incorporarlo. |
| Generación de imágenes | Microsoft Copilot | Microsoft – Plan gratuito | Se utilizó para generar recursos visuales relacionados con la identidad, las funcionalidades y la presentación de LUNA. | Las imágenes generadas pueden presentar elementos deformados o inconsistencias visuales. Se revisaron y editaron los resultados antes de utilizarlos. |
| Generación de video | Vidogrid | Vidogrid – Plan gratuito | Se utilizó como herramienta de apoyo para crear el video promocional del proyecto mediante inteligencia artificial. | El resultado puede presentar movimientos poco naturales o diferencias respecto de lo solicitado. Se revisó el material generado y se realizaron ajustes para mejorar su presentación. |
| Voz y música | Voz propia y grabación personal | Recursos propios – Sin costo | Se utilizó la voz de la integrante para realizar la demostración de la aplicación, con el objetivo de explicar su funcionamiento de manera clara y personal. | Se procuró que la grabación tuviera buena claridad y volumen para facilitar la comprensión del contenido. |
| Diseño y gráficos | Canva | Canva – Plan gratuito | Se utilizó para diseñar y editar piezas gráficas, organizar imágenes y preparar recursos visuales para la presentación del proyecto. | Algunas funciones y recursos pueden estar limitados en el plan gratuito. Se seleccionaron herramientas y elementos disponibles sin costo. |

## Consideraciones

Las herramientas de inteligencia artificial se utilizaron como apoyo durante distintas etapas del proyecto. Las decisiones finales, la revisión de los resultados y la adaptación de los recursos estuvieron a cargo de la integrante.

El uso de estas herramientas no reemplazó el desarrollo, las pruebas ni la validación de las funcionalidades de LUNA.
