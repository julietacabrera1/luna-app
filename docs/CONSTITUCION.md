# CONSTITUCIÓN – LUNA

1. **Stack tecnológico:** el desarrollo de LUNA utiliza React + Vite, JavaScript y CSS en el frontend, Supabase con PostgreSQL para los servicios de backend y almacenamiento, y Netlify para el despliegue de la aplicación.

2. **Identidad visual:** la aplicación mantiene una identidad visual basada principalmente en tonos celestes, azul oscuro, blanco y colores neutros, siguiendo los criterios definidos para la marca LUNA.

3. **Calidad del software:** las funcionalidades deben revisarse y probarse antes de considerarse terminadas. Se deben corregir los errores detectados y verificar que los cambios no afecten otras partes de la aplicación.

4. **Adaptabilidad y accesibilidad:** la interfaz debe adaptarse a celulares, tablets y computadoras. Se debe procurar una experiencia clara y accesible, considerando el contraste, la navegación y los textos alternativos de las imágenes relevantes.

5. **Seguridad de la información:** los datos de los usuarios deben protegerse mediante los mecanismos de autenticación y seguridad de Supabase, el uso adecuado de variables de entorno y la validación de los datos ingresados.

6. **Idioma y comunicación:** el idioma principal de LUNA es el español. La aplicación debe utilizar mensajes claros, cercanos y amigables, manteniendo una comunicación sencilla con sus usuarios.

7. **Uso responsable de inteligencia artificial:** las herramientas de IA pueden utilizarse como apoyo para el desarrollo, la documentación y la generación de recursos visuales. Los resultados deben revisarse antes de incorporarse al proyecto. No se deben compartir datos personales ni información confidencial con estas herramientas.

8. **Organización del código y control de versiones:** mantener el código organizado y seguir las convenciones establecidas en `07-CONVENCIONES.md`. Los cambios deben ser comprensibles y, siempre que sea posible, realizarse en commits pequeños y descriptivos.
